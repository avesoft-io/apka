# Apka

Apka is a multi-tenant office action tracker for patent firms. Each firm is its own organization. A person who registers creates that firm and becomes its supervisor. Users added by a supervisor can sign in only to that firm.

The frontend is Vue 3 rendered through Inertia. Routes used by the pages are generated by Laravel Wayfinder. Styling is Tailwind CSS 4. PHP is checked with Pint and PHPStan level 7.

Session authentication is built into the app. There is no Fortify or Breeze package.

## What a firm can do

- Register a firm, or sign in to an existing one.
- Add users to that firm. A supervisor chooses staff or supervisor. Those users see only that firm's clients, office actions, templates, and history.
- Log an office action with a client, an application number or HCI reference, a paper number, an office action type, a mailing date, and a response period.
- Assign the office action, follow the checklist from the client report through filing, and keep the official deadline, internal response date, and reminder date separate.
- Keep standing instructions on a client.
- Fill email drafts from templates and export a list to Excel.

## Local setup

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run build
php artisan serve
```

`.env.example` uses SQLite. To use MySQL instead, set `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, and `DB_PASSWORD` in `.env`, create the database, then run the migrations.

For frontend hot reload, run `npm run dev` in a second terminal while `php artisan serve` is running.

`composer setup` installs PHP and Node dependencies, creates `.env` when it is missing, generates the app key, migrates, and builds the frontend.

## Tests

```bash
php artisan test
```

Feature tests use an in-memory SQLite database. CI on GitHub Actions runs on PHP 8.3 and Node 22 and executes `composer ci:check`, which lints the frontend, typechecks Vue, runs Pint, runs PHPStan, and runs the test suite.
